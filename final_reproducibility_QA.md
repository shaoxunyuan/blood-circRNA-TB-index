## Notes on the two MINOR items

**Bootstrap selection frequencies (ASXL1, GOLPH3).** The reimplemented bootstrap
reproduced every headline summary exactly — panel size, IQR, the ≤3-genes proportion,
the in-bag and out-of-bag AUROC of the locked panel, and two of the four selection
frequencies. Two individual gene-selection frequencies differ by **one of 500 bootstrap
iterations**: ASXL1 28.2% versus 28.4% in the manuscript, and GOLPH3 18.0% versus 17.8%.
The original greedy routine was traced and its semantics reproduced (candidate set built
by `Reduce(intersect, ...)` so that matrix row order is preserved; strictly-greater
comparison so that the first candidate wins an exact AUROC tie; the full forward path is
walked and the early-stopping rule is applied to the recorded increments). The residual
difference is an **implementation-level exact-tie difference**, not a statistical one:
the panel size, the consensus panel, the locked panel, the AUROC summaries and every
conclusion are unchanged. The script prints the difference rather than absorbing it.

**Step 13 was not re-executed.** The required per-sample benchmark score table is
distributed with the deposited processed data and is not included in the GitHub
repository package, so `code/13_DeLong_comparisons.R` was not run here. Its result file
(`results/DeLong_comparisons.tsv`) is unchanged from the previously verified state and
was checked for structure and internal consistency (16 comparisons, unadjusted and
BH-adjusted *P* values, one BH family) rather than regenerated.

**Step 14 was re-executed** from the final cohort-specific circular isoform tables
(circular isoforms of SOD2, GOLPH3 and PCNX2, restricted to the final IDC / ITC / PVC
library sets, 109 / 35 / 81). Re-running `code/14_BSJ_refinement.R` reproduced
`results/BSJ_summary.tsv`, `results/BSJ_overlap_summary.tsv` and
`results/BSJ_contribution_detail.tsv` **byte-identically** to the shipped files, and the
in-script expected-value QA passed (all-three-cohort junctions 1 / 1 / 12; largest-shared
contributions 95.5 / 89.7 / 73.5, 99.1 / 99.7 / 100.0, 26.4 / 21.8 / 24.9). The junction
identity is the genomic coordinate `BSJ_ID` (`chromosome|donor|acceptor|strand`); no
fixed Top-N junction selection and no IDC-locked-junction validation step is used
anywhere.

Final cohort membership is not assumed from the input tables. `code/14_BSJ_refinement.R`
reads `data/metadata/{IDC,ITC,PVC}_metadata.tsv` and restricts each BSJ table to the
`Sample_ID` list of that cohort, so extra BSJ-input libraries are excluded **by
`Sample_ID` inside the script** (1 ITC library and 19 PVC libraries in the verification
run) and the script stops if the metadata does not describe the final cohort. A final
cohort library with no quantified panel-gene circular isoform row (IDC `TB_11`; PVC
`SAMN13232066`) is reported and contributes zero rather than being silently assumed
present.
